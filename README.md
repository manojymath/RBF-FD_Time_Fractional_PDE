# RBF-FD_Time_Fractional_PDE
RBF-FD Method for time-fractional PDE problems

Title: Highly accurate RBF-FD based method for time-fractional Black-Scholes PDE modeling option pricing problems

Authors: A. Sreedhar, Manoj Kumar Yadav and Chirala Satyanarayana 

This repository contain MATLAB script files for solving time-fractional PDE problems. RBF-FD method of order 2 is used for spatial discretization along with constant and variable shape parameter optimization strategies. Node-dependent variable optimal shape parameter choice leads to fourth-order convergence in space which is beyond the expected second-order convergence. For time discretization, the widely used L1 formula is used for approximating the Caputo fractional order derivative.
